# Trivvi

A food discovery app for Toronto that gives you a personalized restaurant recommendations based on your taste, dietary needs, and neighbourhood. No more scrolling, just decisive picks.

## Tech Stack
- Frontend  : either react Native or Swift/Kotlin 
- Backend : Golang with Python service 
- Database : PostgreSQL
- Deployment : GCP AWS or Azure or whatever
- ML: Python, FastAPI, scikit-learn, scipy

## ML Service
(gabs work)
- Hybrid recommendation engine combining collaborative filtering (SVD) and content-based filtering
- Trained on synthetic Toronto restaurant data (300 restaurants, 500 users, 8000 interactions)
- REST API built with FastAPI
